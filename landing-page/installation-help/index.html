Installation help

Get TaskMaster Pro running

Applies to the version shown on the download card

Windows 10 and Windows 11

  1. Download the Windows installer from the official GitHub release.
  2. Open the downloaded TaskMaster Pro Windows installer.
  3. Review any Windows security prompt, then continue the installer.
  4. Launch TaskMaster Pro from the Start menu or desktop shortcut.

Android phones and tablets

  1. Download the signed TaskMaster Pro Android package.
  2. Open the downloaded APK from your browser or Files application.
  3. If Android asks, allow installation from that source for this install.
  4. Review the package details and confirm installation.
TaskMaster Pro never starts an installation without your action. Windows may show a reputation warning for a new, unsigned release, and Android requires confirmation before installing an APK outside an app store.

Check your download

Every official release includes a verification file beside each installer. You can use it to confirm that the download has not changed before opening it.
