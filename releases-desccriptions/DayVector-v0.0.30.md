# DayVector 0.0.30 — What's new

DayVector 0.0.30 makes daily planning feel more connected, more flexible, and easier to use in your own language.

## Highlights

- **Polish language support:** Polish joins English, Arabic, and German in a modern language dropdown on the website and in the app.
- **Reliable task navigation:** Dashboard actions now lead to the exact task you selected.
- **More resilient device synchronization:** Running, paused, break, and completion updates use an additional direct real-time delivery route and a guarded recovery path when a device reconnects or misses an event.
- **Self-healing settings sync:** DayVector validates settings changes before they leave your device. A damaged legacy settings update is repaired once when safe; otherwise the app restores the confirmed server settings instead of leaving synchronization stuck on an error.
- **Native work scheduling:** Set a practical weekday routine, then tailor rotating shifts, work reminders, and optional Pomodoro support without creating a fake work task. Regular weekly schedules now receive the same reminders as rotating schedules, and enabling a reminder after its usual lead time still alerts you for the upcoming shift instead of silently skipping to next week.
- **Accurate daily planning:** The Planned total now counts every scheduled task card and its planned rest. If a new task would exceed the awake-time window in your day rhythm, DayVector keeps the existing plan intact and takes you back to scheduling so you can choose a realistic date.
- **Clearer activity decisions:** Review an unfamiliar application by category first—work support, communication, reading or research, learning, distraction, or system activity—and see whether the choice is generally useful. DayVector asks whether to remember your decision for future captures; optional community learning is privacy-first and uses anonymous hashes and aggregate votes only, never your task names, app names, URLs, or activity timeline.
- **Readable release notes:** Update notes now render safe Markdown and common GitHub disclosure blocks, including `<details>` and `<summary>`, as expandable in-app sections instead of showing raw HTML.
- **A less crowded landing page:** The Polish-language announcement is now a timed in-page update card instead of a navigation item. It remains easy to update and automatically expires on its configured date.

## Your data stays yours

This update preserves existing tasks, roadmaps, settings, and local data. You remain in control of activity permissions, community-learning participation, work scheduling, and notifications.
