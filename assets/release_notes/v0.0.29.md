# TaskMaster Pro 0.0.29

- Synchronization now settles to a truthful idle state, automatically catches up after Realtime reconnects, and separates internal repair work from changes that need your attention.
- Paused tasks stop accumulating time immediately. After 12 hours, the app offers clear actions to return the task to the list or skip it without affecting another running task.
- Performance reports cap an active Pomodoro at its current focus boundary and never count paused wall time as productive work.
- Recovery controls remain usable on narrow phones and are fully translated in English, Arabic, and German.

This release keeps the legacy TaskMaster Pro Supabase project and its local caches isolated from the clean project.
