# DayVector 0.0.29

- DayVector 0.0.29 introduces the new logo and a consistent identity across Windows, Android, notifications, widgets, reports, and installers.
- Starting, pausing, resuming, breaking, or finishing work now converges automatically across signed-in devices. A task started on one device appears on the other without waiting for another action.
- Derived roadmap forecasts no longer create cross-device revision conflicts, and task changes already present on the server are recognized and cleared automatically.
- Tasks can include an optional planned rest, such as a 30-minute lunch. Rest stays separate from expected work time and travels with the task across devices.
- Android widget and notification controls act directly without opening the app, while the widget and in-app timer use the same canonical session state.
- Health summaries, sleep data, recovery guidance, sync diagnostics, and responsive layouts are clearer on phones and Windows. Canonical Health Connect exercise sessions remain visible even when optional workout details are unavailable.

Your existing account, tasks, progress, and local data remain available after the update.
