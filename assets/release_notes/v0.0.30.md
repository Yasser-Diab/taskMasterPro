# TaskMaster Pro 0.0.30

- Focus and break notifications are now retained and delivered on Windows with exact task, session, revision, and boundary identity. Ordinary reminders can no longer replace a live-session alarm, and scheduling failures are reported truthfully.
- When a break has no meaningful device activity, the app optionally asks whether you were reading, exercising, relaxing, having a drink, or doing something else. You can assign the activity to an existing task or leave it unassigned.
- Manual break activities synchronize as privacy-safe normalized records. Raw process, window, page, and browsing details are never accepted for these entries.
- Exercise check-ins teach the adaptive coach about recent activity and can trigger an immediate encouraging coaching notification.
- Synchronization now converges automatically without repeated full-table reloads, while internal runtime cleanup no longer appears as a user conflict.
- Activity attention uses one date-scoped, grouped review model everywhere. Active capture rows are no longer counted as inactive, dashboard counts match Activity, and the task-allocation dialog remains usable with long task lists.

The legacy Supabase project remains isolated; these changes target only the clean TaskMaster Pro project.
