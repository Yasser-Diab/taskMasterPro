# DayVector 0.0.30

## A calmer, more connected DayVector

- **Polish is now available.** Choose English, Arabic, German, or Polish from the new language dropdown on the website and in the app.
- **Tasks now open where you expect.** Selecting a task from the dashboard opens that task's own workspace rather than another task.
- **Faster cross-device task updates.** DayVector now has an additional direct real-time path for the shared running, paused, break, and completed state, with guarded recovery when a device misses an event.
- **Work schedules belong in DayVector.** Start with a neutral weekday rhythm, then enable native work scheduling, rotating weekly shifts, pre-work reminders, and an optional Pomodoro suggestion without creating a placeholder task.
- **Activity review is clearer.** App classifications can distinguish useful work from non-productive activity. Optional community learning only shares anonymous hashes and aggregate category votes; it never sends an app name, task, URL, or activity history.
- **A clearer website update notice.** The Polish announcement appears in page content instead of crowding the navigation, and automatically expires after its configured date.

Your tasks, roadmaps, preferences, and local data remain in place after updating.
