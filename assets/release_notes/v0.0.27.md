# What’s new

- One canonical task-control flow across the Dashboard, Execute workspace, tray, and Android notification actions
- Countdown-first continuous and Pomodoro timers with theme-aware holographic presentation
- Real task domains, recurring-task projection, task resources, interruptions, and report drill-downs
- Health Connect daily summaries with source attribution, task overlap, and height-based distance estimates

# Fixed issues

- Legacy Activity commands are repaired into the current atomic classification format instead of retrying forever
- Realtime bursts are batched and an old zero synchronization cursor no longer downloads the full account history repeatedly
- Health headline totals reset at the local day boundary and never reuse yesterday’s steps as today’s value
- Reports resolve task, roadmap, phase, and domain names instead of exposing database identifiers
- Duplicate legal links were removed from App updates

# Important notices

- A health provider is shown only after TaskMaster Pro reads a real attributed record
- Direct Bluetooth reports only capabilities exposed by the connected watch
- Raw unapproved Activity details remain local unless detailed Activity synchronization is enabled
