# TaskMaster Pro 0.0.28

- Rebuilt task timing, Pomodoro transitions, overtime, and notification actions around one revision-aware command path.
- Added delivery-time suppression for obsolete Android focus, break, and task-duration alarms.
- Made routine synchronization converge automatically with event-driven recovery and substantially lower idle traffic.
- Restored imported roadmap schedules, targets, and task website resources from the clean TaskMaster Pro project.
- Improved narrow-phone dashboard, task editor, synchronization, browser, and Connections layouts.
- Added durable task-browser checkpoints, reliable Android page recovery, and Google sign-in through Android Custom Tabs.
- Rebuilt report time accounting around non-overlapping interval unions, normalized application/site names, and evidence-based forecasts.
- Improved paired health-source discovery, encrypted Vault unlocking, Activity classification, and English, Arabic, and German presentation.
- Widget and notification controls now apply Pause, Continue, Break, Extend, Focus, and Finish directly in a revision-guarded background command without opening the app. Each Android action has a unique task/session identity, so Continue can never be reused as Finish.
- The responsive Android widget now follows the current running, paused, or break state and refreshes its timer and controls immediately after a background action.
- Break completion creates an optional private activity check-in when no meaningful device activity was observed, with reading, exercise, relaxation, drink, other, and task-assignment choices. Exercise check-ins can trigger encouraging coaching.
- Focus and break notification cards keep their exact task, session, revision, and boundary identity, while live status and audible boundary alerts use separate notification slots.
- Activity attention totals and grouped review filters now use one date-scoped model, and ordinary synchronization converges without repeated full-table downloads or internal cleanup conflicts.
- Health and rest now uses a modern phone and Windows dashboard with rounded values, a seven-day movement view, swipe refresh, connected sources in one panel, and no grey expansion/scroll failure.
- Health Connect sleep sessions and their light, deep, REM, awake, and out-of-bed stages are now combined into one accurate sleep total without double-counting repeated stage records.
- Dashboard task controls now share consistent touch sizes, coaching is calmer and more compact, and each working style offers optional friendly guidance from a small information button.
- Device-only Health freshness metadata, Android task-resource permissions, and completed-runtime projections no longer create false synchronization conflicts or hundreds of changes needing attention.

This release keeps the legacy TaskMaster Pro Supabase project and its local caches isolated from the clean project.
