# What’s new

- Faster, more reliable synchronization between Windows and Android
- A working Password Vault for protected saved accounts
- Clickable synchronization status with pending changes and connected devices
- Profile pictures now remain available after synchronization and restart
- Account deletion now includes a 30-day recovery period

# Improvements

- Every task now includes activity analysis and a review warning when unresolved activity exceeds half of a session
- Health Connect summaries can be approved for synchronization to Windows
- Schedule, sleep, quiet hours, and wellbeing settings are available together
- The Calendar control now names the visible Month, 2 weeks, or Week view correctly
- Coaching uses a welcoming learning state before enough personal history exists

# Fixed issues

- Device registration no longer breaks when different accounts use the same installation
- Task-to-roadmap and roadmap-phase changes synchronize correctly
- Profile-image uploads preserve the previous picture when an upload fails
- Settings from two devices merge by changed field instead of overwriting unrelated preferences
- Notification sounds and action payloads use stable platform channels

# Important notices

- Vault passwords, usernames, private notes, and recovery information are encrypted on the device before synchronization
- Raw website cookies and sign-in session tokens remain on the device and are never synchronized
- Health information is planning context only and is not a medical diagnosis
