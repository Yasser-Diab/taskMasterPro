# DayVector 0.0.29

- DayVector 0.0.29 führt das neue Logo und eine einheitliche Identität unter Windows, Android, in Benachrichtigungen, Widgets, Berichten und Installationsdateien ein.
- Das Starten, Pausieren, Fortsetzen, Unterbrechen und Abschließen einer Aufgabe wird nun automatisch zwischen angemeldeten Geräten abgeglichen. Eine auf einem Gerät gestartete Aufgabe erscheint ohne weiteren Befehl auf dem anderen.
- Berechnete Roadmap-Prognosen verursachen keine geräteübergreifenden Revisionskonflikte mehr. Ist eine Aufgabenänderung bereits vollständig auf dem Server vorhanden, erkennt DayVector sie und entfernt den doppelten Befehl automatisch.
- Aufgaben können eine optionale geplante Pause enthalten, zum Beispiel eine 30-minütige Mittagspause. Die Pause bleibt von der erwarteten Arbeitszeit getrennt und wird mit der Aufgabe synchronisiert.
- Android-Widgets und Benachrichtigungen führen Aktionen direkt aus, ohne die App zu öffnen. Widget und App verwenden denselben verbindlichen Sitzungsstatus.
- Gesundheitsübersichten, Schlafdaten, Erholungshinweise, Synchronisierungsdiagnosen und responsive Ansichten sind auf Telefonen und unter Windows übersichtlicher.

Dein bestehendes Konto, deine Aufgaben, dein Fortschritt und deine lokalen Daten bleiben nach dem Update erhalten.
